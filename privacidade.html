Política de Privacidade

  1. O que é acessado: apenas as permissões user.info.basic (nome e foto do perfil, para confirmar a conta conectada) e video.upload (enviar vídeo para os rascunhos).
  2. Onde fica: o token de acesso fica guardado só no computador do criador. Nenhum servidor externo recebe esses dados.
  3. Compartilhamento: nenhum dado é vendido, compartilhado ou usado para publicidade.
  4. Dados de outras pessoas: a ferramenta não coleta dados de seguidores nem de outros usuários.
  5. Exclusão: ao revogar o acesso no TikTok ou apagar o arquivo local de configuração, o token deixa de existir.
  6. Contato: pelo perfil @rprado3d no TikTok.

English: The tool only uses the scopes user.info.basic (to confirm the connected account) and video.upload (to send videos to drafts). The access token is stored only on the creator's computer and is never sent to any external server. No data is sold, shared or used for advertising, and no data from followers or other users is collected. Revoking access in TikTok or deleting the local configuration file removes the token. Contact: @rprado3d on TikTok.
